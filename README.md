# CoinCounter – Android Application

## Overview
CoinCounter is an Android application designed to recognise and count British pound sterling (£) coins from photographs using machine-learning-based image recognition.

## Key Features
- Detects and classifies UK pound sterling coins from images
- Calculates the total value of detected coins in GBP (£)
- Uses an object-detection model with image-processing logic
- Includes validation of model outputs and coin classifications

## Example Test
In a test using a real photograph, the application identified UK coins with a gave a combined value of £6.52 matching the physical coin count.
